# Intermediate path

This route is for practitioners who are comfortable with Python projects,
Parquet data, configuration files, and basic local services. It introduces
point-in-time evaluation, model metrics, graph workflows, and controlled
quality failures.

**Level:** Intermediate<br><br>
**You will:** create reproducible datasets and evaluation runs, inspect quality<br><br>
and drift, and choose optional integrations deliberately.
**Before you start:** complete the [Beginner path](beginner.md) and have a<br><br>
working FraudTwin environment.
**Services:** None for the core route; Docker is optional for integrations.<br><br>

## Follow this route

1. Learn the full configuration surface in [Configuration](../configuration.md)
   after trying the minimal example.
2. Build point-in-time datasets and backtests with [Data and evaluation
   workflows](../workflows.md).
3. Review the measurement rules in [ML evaluation](../ml-evaluation.md) and
   [Drift and shift](../drift-and-shift.md).
4. Use [Data-quality incidents](../data-quality-incidents.md) to inject,
   replay, and repair known faults.
5. Explore [Graph and benchmark workflows](../graph-and-benchmarks.md) when
   relationships or adversarial difficulty matter.
6. Continue to [Model lifecycle](../model-lifecycle.md) when an experiment
   needs tracked artifacts or a serving hand-off.

## Next

Move to the [Expert path](expert.md) when you need service boundaries,
streaming contracts, scale operations, extensions, or release evidence.
