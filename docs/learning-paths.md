# Learning paths

**Level:** All levels<br><br>
**You will:** choose a single, connected route through the canonical FraudTwin<br><br>
guides.
**Before you start:** none; choose the route that matches your experience.<br><br>
**Services:** None.<br><br>

FraudTwin documentation is organized by how much software and data-engineering
experience you bring. Pick one route, follow its links in order, and return to
the canonical guide whenever you need deeper detail.

| Route | Best for | Start here |
| --- | --- | --- |
| [Beginner](levels/beginner.md) | Python users who are comfortable with notebooks and package installation | Install FraudTwin and create your first run |
| [Intermediate](levels/intermediate.md) | Practitioners who work with data pipelines, ML experiments, or local services | Configure a run and build an evaluation workflow |
| [Expert](levels/expert.md) | Engineers responsible for integrations, operations, extensions, or release quality | Understand the boundaries, contracts, and operational guarantees |

These routes are not separate versions of the product. They are navigation
layers over one set of maintained guides, so a concept has one authoritative
explanation and one set of examples.

## Find a route by role

If your job is a better starting point than your experience level, use the
[role index](audiences.md). It links analysts, data scientists, engineers,
researchers, and governance reviewers to the same level-based guides.
