# Getting started with FraudTwin

Follow this path to understand the generated world before adding fraud or
machine learning. It runs locally with the base installation and establishes
the identities, timestamps, ledger, and observable/oracle boundary used by
later tutorials.

| IDs | Time | Extras | Output |
| --- | --- | --- | --- |
| 1–2 | 20–30 min | base install | run manifest and configuration tables |
| 3–4 | 30–45 min | base install | lifecycle tables and delayed-label view |
