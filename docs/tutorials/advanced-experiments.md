# Advanced experiments

These four workflows expose FraudTwin capabilities that are easy to miss in
the core learning path. Each combines related APIs into a complete analysis;
the old numeric routes remain compatibility redirects in published builds.

| Workflow | Offline | Main artifact |
| --- | --- | --- |
| Calibration and counterfactual fraud experiments | Yes | calibration profile and intervention manifest |
| Campaign dynamics and graph investigation | Yes | lineage and as-of evidence report |
| External predictions, temporal backtesting, and feature shift | Yes | evaluation, t-SNE, and drift report |
| Scale benchmarking, reconciliation, and experiment packaging | Yes | benchmark, invariant, and experiment bundle |
