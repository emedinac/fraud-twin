# New users

**Level:** Beginner<br><br>
**You will:** install FraudTwin, create a local run, and learn where its<br><br>
manifest and Parquet artifacts come from.
**Before you start:** Python 3.12 or newer and a terminal.<br><br>
**Services:** None.<br><br>

Start with [installation](../installation.md), [quickstart](../quickstart.md),
and the [Beginner path](../levels/beginner.md). The existing
[visualization tutorial path](../tutorials/visualization.md) is a useful next
step when you want to explore the generated data in a notebook. The starter
route is fully offline.
