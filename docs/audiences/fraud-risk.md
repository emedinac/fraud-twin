# Fraud and risk practitioners

**Level:** Beginner to Intermediate<br><br>
**You will:** compare fraud scenarios, understand label availability, and read<br><br>
observable and oracle evidence without confusing the two.
**Before you start:** a generated run or the [quickstart](../quickstart.md).<br><br>
**Services:** None; Neo4j is optional.<br><br>

**Start with:** [Concepts](../concepts.md), [fraud scenario exploration](../tutorials/fraud-scenarios-difficulty-benchmarks.ipynb),
and [graph investigation](../tutorials/graph-analytics.md).

This path is for fraud analysts, risk investigators, and model-risk partners.
Use observable views for decisions and oracle views for explanation and audit;
all examples run offline. Neo4j is an optional local enhancement. Your first
artifact is a scenario comparison or an as-of investigation report.
