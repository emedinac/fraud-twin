# Data, platform, and MLOps engineers

**Level:** Expert<br><br>
**You will:** connect optional services while preserving source artifacts,<br><br>
contracts, and reproducibility.
**Before you start:** a working local run and Docker familiarity.<br><br>
**Services:** depends on the selected integration.<br><br>

**Start with:** [integration runbooks](../integrations.md), [Kafka reliability](../kafka-reliability.md),
and the [Expert path](../levels/expert.md).

This path covers persistence, streaming, lakehouse projections, model hand-off,
and observability. Every guide has an offline fallback; Docker services are
used only for local integration smoke checks. Your first artifact is a bounded
reconciliation manifest or a validated serving request/response trace.
