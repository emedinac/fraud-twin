# Researchers and governance reviewers

**Level:** Intermediate to Expert<br><br>
**You will:** review reproducibility, source boundaries, schema changes, and<br><br>
claims without treating synthetic evidence as real-world performance.
**Before you start:** a generated run and the [concepts guide](../concepts.md).<br><br>
**Services:** None for review workflows.<br><br>

**Start with:** [data contracts](../data-contracts.rst), [compatibility policy](../compatibility.md),
and the [Expert path](../levels/expert.md).

This path is for benchmark authors, educators, data-governance reviewers, and
model-risk teams. Use fixed seeds, manifests, schema versions, labels-at-time,
and fingerprints. Synthetic evidence demonstrates system behavior; it is not a
claim of real-world detector performance. All review steps run offline.
