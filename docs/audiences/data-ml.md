# Data and ML practitioners

**Level:** Intermediate<br><br>
**You will:** build point-in-time-safe data, evaluate predictions, and inspect<br><br>
drift without changing the source simulation.
**Before you start:** a generated run and basic Parquet familiarity.<br><br>
**Services:** None for the core route; MLflow is optional.<br><br>

**Start with:** [point-in-time workflows](../workflows.md), [ML evaluation](../ml-evaluation.md),
and the [Intermediate path](../levels/intermediate.md). The existing
[visual exploration tutorials](../tutorials/visualization.md) remain the best
notebook-first introduction to the data.

This path is for data scientists, applied ML engineers, and quantitative fraud
researchers. The analysis path is offline and uses the `ml` extra only when you
need scikit-learn baselines, PCA, or t-SNE. Your first artifacts are a schema
report, leakage check, metric table, and reproducibility fingerprint.
